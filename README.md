# Selecting-a-Car
for selecting the best car out of two you should calculate the total cost so for that you should first 
calculate the operating cost for each car and then add with the purchase price 
for calculate the operating you should calculate the annual fuel consumed which is equal to the annual miles drive / fuel efficiency
then caculate annual fuel cost(for one year) which is equal to the price per gallon * the annual fuel consumed
after that caculate the annual fuel cost for length of time which given in the question which is 10 years by multiply the annual fuel cost with 10
then find the total cost which is equal to operating cost + purchase price and finally compare them so which has the lowest total cost is the best so i select it .
